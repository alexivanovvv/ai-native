01

Суть подхода в одном абзаце

AI Native - это не про инструменты, они все время меняются. Это про систему: одна база знаний (весь ваш контекст) + AI-инструменты под задачи (действия) + инструкции, скиллы и агенты, которые их соединяют. Вы - дирижер этого оркестра. Ключевой вопрос, который вы теперь задаете себе про любой процесс: «Как мне делать это иначе, имея AI в своей команде?»

02

6 принципов AI Native

01
Контекст важнее промптов

Хорошо собранный контекст - это уже 80% результата. Промпт может быть в одно предложение.

02
Правило 0 → 80 → 100

AI делает первые 80% за минуты, вы доводите финальные 20%. Экономия не 20%, а 70-80%.

03
Система, а не чаты

Вместо 200 разрозненных чатов - Personal OS: база знаний + память + инструкции + скиллы + агенты.

04
Верный инструмент под задачу

Небольшой стек, где под каждую типовую задачу есть свой инструмент. Без FOMO на каждый новый сервис.

05
Суждение: с AI или без

Знать, когда AI не нужен: суть задачи - подумать самому, нужен личный голос, высоки ставки, важна человеческая связь.

06
Скиллы и агенты для повторяющегося

Все, что повторяется, превращаем в скилл или агента и выводим себя за скобки.

03

Из чего состоит ваша Personal OS

A
Знания - весь контекст
  • База знаний в одном месте: локально (md + Obsidian) или в облаке (Google Drive)
  • aboutme.md - все важное о вас
  • Память, выгруженная из ваших LLM
  • Swipe-файлы - лучшие практики по областям
  • Библиотека промптов
  • Системный промпт в основном LLM
B
Действия - инструменты

Поиск, исследования, транскрибация звонков, голосовой ввод, картинки, работа с файлами, кодинг, автоматизации.

Составьте свой список «задача → инструмент» на 10-15 основных задач.

C
Инструкции и автономия
  • Agents.md / Claude.md - правила и описание вашей базы для AI
  • Скиллы - шаблонные повторяемые задачи
  • Агенты - автономные помощники, сами выбирают инструменты
  • Автоматизации - например, транскрипты сами попадают в базу

Форматы файлов: md (лучший для LLM), txt, csv, pdf - чем легче, тем проще LLM работать со всем вашим контекстом.

04

Скилл или агент - простое правило

Скилл /

  • Шагов мало и они простые
  • Есть понятный шаблон
  • Продолжительность задачи небольшая
  • Автономная многоходовая работа не требуется

Агент @

  • Несколько шагов и нужны итерации
  • Задачи сложные, не по простому шаблону
  • Требуется автономная работа в несколько ходов
  • Агент сам выбирает инструменты в рамках задачи

06

Библиотека скиллов на GitHub

Готовые скиллы с интенсива лежат в открытом репозитории - контент-пак, генератор слайдов и лендингов, подготовка к встречам, Q&A из транскриптов и другие. Не нужно ничего собирать руками: дайте своему агенту ссылку, и он установит скилл сам.

github.com/alexivanovvv/ai-native · SKILLSОткрытая библиотека скиллов интенсива AI Native
  1. Выберите скилл

    Откройте репозиторий, зайдите в папку SKILLS/ и посмотрите README нужного скилла - что он делает и что ему нужно.

  2. Дайте агенту ссылку и попросите установить

    Скилл - это просто папка с файлом SKILL.md внутри ~/.claude/skills/. Claude Code (или Cowork) сам скачает файлы, прочитает инструкции и поставит зависимости. Готовый промпт - ниже, просто подставьте имя скилла.

  3. Проверьте вызов

    Перезапустите сессию и вызовите скилл: /имя-скилла - или опишите задачу словами, агент сам поймет, что скилл подходит.

Установи мне скилл content-pack из репозитория
https://github.com/alexivanovvv/ai-native (папка SKILLS/content-pack).

Скачай файлы скилла в ~/.claude/skills/content-pack/, прочитай SKILL.md,
установи зависимости, если они нужны, и покажи пример, как его вызвать.

Промпт универсальный - замените content-pack на любой скилл из репозитория. Работает в Claude Code, Claude Cowork и совместимых агентах (Codex и др. - путь к папке скиллов может отличаться, агент разберется).
