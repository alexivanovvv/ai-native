# Reusable prompts

Промпт работает лучше, когда рядом с ним есть контекст, примеры и критерии качества. Используйте шаблоны как отправную точку, а не как магические заклинания.

## Разобрать сложную задачу

```
Помоги мне разобраться с задачей.

Контекст:
[что происходит]

Желаемый результат:
[что должно быть готово]

Ограничения:
[сроки, ресурсы, правила]

Сначала:
1. Сформулируй, как ты понял задачу.
2. Назови недостающий контекст.
3. Предложи 2-3 возможных подхода с trade-offs.
4. Рекомендуй следующий шаг.

Не начинай выполнять задачу, пока не обозначишь критические допущения.
```

## Red team решения

```
Проведи red team моего решения.

Контекст:
[ситуация]

Решение, к которому я склоняюсь:
[решение]

Найди:
1. самые сильные аргументы против;
2. слепые зоны;
3. вторичные последствия;
4. риски, которые проявятся только со временем;
5. альтернативу, которую я не рассматриваю.

Не соглашайся со мной ради вежливости. Отделяй факты от предположений.
```

## Синтез встречи

```
Проанализируй этот транскрипт встречи и выдай:

1. тему встречи в 1-2 предложениях;
2. принятые решения;
3. открытые вопросы;
4. action items с ответственными и сроками;
5. важные сигналы между строк.

Не додумывай то, чего нет в транскрипте. Если ответственный или срок не названы, пометь это как неизвестное.
```

## Улучшить рабочий процесс

```
Вот как сейчас устроен мой процесс:

[пошаговое описание]

Результат, который мне нужен:
[результат]

Найди:
1. лишние шаги;
2. места, где можно использовать AI;
3. места, где AI использовать не стоит;
4. какие данные и контекст нужно сохранять;
5. минимальный эксперимент на эту неделю.

Сохрани человеческие точки контроля: качество, этику, финальное решение и ответственность.
```
