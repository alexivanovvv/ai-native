# AI Native

AI Native is a practical approach to working with AI as a teammate from the first second of a task.

It is not mainly about collecting tools or writing clever prompts. It is about redesigning how you work when AI can help with context, research, thinking, production, critique, and repetitive execution.

## Core idea

The shift is from:

> "How do I write a better prompt?"

to:

> "How would I redesign this process if AI were part of the team from the beginning?"
