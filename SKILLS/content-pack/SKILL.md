# /content-pack — тема → пост TG + Shorts/Reels + YouTube (+ обложка)

## Usage

```
/content-pack "тема"
/content-pack "тема" --channel ppprompt     # целевой канал для поста (default: ponchiknews)
/content-pack "тема" --tg-only              # только пост
/content-pack "тема" --no-save              # показать в чате, не сохранять файл
/content-pack "тема" --with-image           # + обложка-картинка для поста (бывший /postcraft)
/content-pack "тема" --with-image --brand "название серии"   # подпись снизу картинки
/content-pack "тема" --series 3             # серия из N постов, нумерованные файлы
```

Тема может быть любой: мысль, вопрос, событие, ссылка, сырой абзац.

Флаг `--with-image` включает режим, эквивалентный бывшему `/postcraft`: быстрый TG-пост с обложкой без полного пакета из трёх форматов. Обычно используется вместе с `--tg-only --with-image` — тема → ресёрч → пост + картинка, без Shorts/YouTube сценариев. Без `--tg-only` картинка всё равно генерируется и используется как обложка Telegram-поста, а Shorts/YouTube пишутся как обычно.

## Процесс

### Шаг 1. Стиль
Прочитай `STYLE.md` рядом с этим файлом — это выжимка авторского стиля из реальных постов. Соблюдай её жёстко, особенно раздел 4 (форматирование: короткое тире, е не ё, без болда в личных постах) и раздел 6 (анти-паттерны).

Если нужно больше примеров живого голоса — открой `CONTENT/Posts/Post Archive/Топ постов Ponchik news.md` в vault.

### Шаг 2. Свежие мысли из транскриптов (ОБЯЗАТЕЛЬНО)
Найди, что Алексей недавно говорил по этой теме вслух — там свежие формулировки, метафоры и кейсы, которых нет в старых постах:

0. Сначала загляни в банк идей `CONTENT/Идеи из транскриптов - YYYY-MM.md` (последний по дате) — там уже выжаты идеи с источниками; если тема покрыта, можно не перечитывать транскрипты.
1. `qmd search --collection alex-ivanov-main-vault "<тема и синонимы>"` — семантический поиск по vault.
2. Grep по свежим транскриптам (последние ~2 месяца):
   ```
   grep -ril "<ключевые слова>" "_TRANSCRIPTS/" "PROJECTS/13 AI NATIVE/"
   ```
3. Прочитай 2-4 самых релевантных транскрипта (места вокруг вхождений). НЕ бери файлы из PRIVATE и терапию.

Из найденного выпиши: 2-3 живые формулировки/метафоры Алексея (близко к тексту), 1-2 кейса или истории (анонимизируй клиентов: «клиент на сессии», «участник спринта»). Если по теме в транскриптах пусто — так и скажи в результате и опирайся на стиль + известный контекст Алексея (aboutme, проекты).

### Шаг 3. Генерация трёх форматов

**1) Пост для Telegram** (канал по флагу или по логике: личное/психология/AI+жизнь → @ponchiknews; инструменты/новости AI → @ppprompt):
- структура и длина — по STYLE.md раздел 2 или 7
- хук из паттернов раздела 3, финал — вопрос-зеркало
- подпись канала последней строкой

**2) Сценарий Shorts/Reels (30-60 сек, ~100-150 слов):**
- формат: `ХУК (0-3 сек)` → `СЕТАП (3-15 сек)` → `ПОВОРОТ/ИНСАЙТ (15-40 сек)` → `ФИНАЛ + CTA (40-60 сек)`
- писать как речь, не как текст: короткие фразы, обращение «вы», разговорные связки
- в начале каждого блока — таймкод и пометка для монтажа [в кадре / b-roll / текст на экране]

**3) Сценарий YouTube (7-8 мин, ~1000-1200 слов речи):**
- структура: холодный хук (15 сек) → интро + доверие (30 сек, кто я — одна строка без хвастовства) → 3-4 смысловых блока с историями/кейсами → практическая часть (что сделать зрителю) → финал + CTA (подписка + вопрос в комментарии)
- заголовки блоков с таймкодами, пометки для монтажа в [скобках]
- метафоры и кейсы — из транскриптов (шаг 2), не выдуманные

### Шаг 4. Хуманизация
Прогони все три текста через принципы скилла `/humanizer`: убрать AI-словарь, rule of three, длинные тире, инфляцию значимости. Проверка вслух: «сказал бы Алексей эту фразу голосом?»

### Шаг 4.5. Обложка-картинка (если `--with-image`)
Вызови `make_image.py` (тот же движок, что раньше был у `/postcraft`):
```bash
python3 ~/.claude/skills/content-pack/make_image.py \
  --main "ключевое слово" \
  --sub "короткий дескриптор (5-8 слов)" \
  --top "@channel_handle  |  t.me/channel" \
  --bottom "серия / бренд (из --brand)" \
  --out /path/to/image.png
```

**Правила для `--main`:**
- Для команд/скиллов: `/skill-name` (со слешем)
- Для концептов, слов: просто слово без слеша
- Максимум ~20 символов; длиннее — сократить или разбить на 2 строки (пока не поддерживается)

**Правила для `--sub`:**
- Суть в 5-8 словах, не повторять main
- Кириллица или латиница в зависимости от поста

**Стилизация картинки (значения по умолчанию — тёплый бежевый Anthropic-стиль):**
- `--bg` фон (default `#EAE2D5`)
- `--accent` цвет слеша и разделительной черты (default `#CC785C`, Book Cloth)
- `--text` основной текст (default `#191919`)
- `--desc` дескриптор (default `#666663`)
- `--labels` верхний/нижний лейблы (default `#777777`)
- `--width` / `--height` (default 1280×720)

Fonts: `~/.claude/skills/content-pack/JetBrainsMono-Bold.ttf` и `JetBrainsMono-Regular.ttf` (автофоллбек на Menlo, если шрифты не найдены).

### Шаг 5. Сохранение
Если нет `--no-save`:
- Без `--series` (или `--series 1`): сохрани один файл `CONTENT/Content Packs/YYYY-MM-DD - <Тема>.md` (создай папку если нет)
- С `--series N` (N > 1): сохрани N файлов, нумерованные `01_slug.md`, `02_slug.md` и т.д. в той же папке `CONTENT/Content Packs/` (slug — латиницей/транслитом от темы)
- структура файла: frontmatter (type: content-pack, topic, date, sources — список транскриптов) + секции `## Пост (@канал)`, `## Shorts / Reels`, `## YouTube (7-8 мин)`
- пост — в code block для копирования одним тапом
- если `--with-image`: вставь картинку прямо перед постом через `![]({slug}.png)`, сохрани `{slug}.png` рядом с md-файлом (тот же базовый slug, что у .md)
- открой файл(ы) в Obsidian: `obsidian://open?vault=Alex%20Ivanov%20MAIN%20Vault&file=<percent-encoded path>`

### Шаг 6. Результат в чате
Покажи все три текста целиком + одной строкой источники из транскриптов (какие свежие мысли использованы и откуда).

## Правила

- Кейсы клиентов — всегда анонимно, без имён (кроме публичных историй, которые Алексей сам рассказывал в канале).
- Не выдумывать факты, цифры и истории «от лица Алексея» — только то, что есть в транскриптах/vault, либо явно нейтральные обобщения.
- Vault path: `~/Library/CloudStorage/Dropbox/_Obsidian/Alex Ivanov MAIN Vault/`
