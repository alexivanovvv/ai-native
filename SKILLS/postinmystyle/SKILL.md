# Напиши пост в стиле Алексея Иванова

## Шаг 1: Загрузи контекст стиля

Прочитай два файла из Obsidian-волта для понимания стиля:

1. `~/Library/CloudStorage/Dropbox/_Obsidian/Alex Ivanov MAIN Vault/PROMPTS/PonchikNews Post v3.md` — основной промпт со структурой и примером
2. `~/Library/CloudStorage/Dropbox/_Obsidian/Alex Ivanov MAIN Vault/CONTENT/Posts/other posts/Авторский стиль Алексея Иванова.md` — полное описание стиля

## Шаг 2: Определи тему

Тема передается как аргумент скилла. Если тема не задана или слишком общая — задай 2-3 уточняющих вопроса:
- Есть ли личная история или наблюдение, от которого отталкиваться?
- Какой инсайт или мысль хочется передать?
- Для какой площадки (Telegram @ppprompt — длинный пост ~150-200 слов, Threads — короткий 50-100 слов)?

По умолчанию пиши для Telegram @ppprompt.

## Шаг 3: Напиши пост

Следуй структуре из PonchikNews Post v3:

1. **Заголовок-крючок** — вопрос или интригующая фраза (до 10 слов)
2. **Личная история** — конкретная ситуация, момент, деталь
3. **Контраст** — "было/стало" или "обычно думают X, но на самом деле Y"
4. **Инсайт** — переформулировка: "это не про A, это про B"
5. **Мета-уровень** — что это говорит о нас/жизни вообще
6. **Финал** — вопрос-зеркало читателю

### Критические правила форматирования

- Только plain text — БЕЗ жирного, курсива, подчеркивания
- Только короткое тире (-), НЕ длинное (—)
- Буква е вместо ё — всегда "еще", "все", "ее"
- Без эмодзи в тексте поста
- Плавные связные предложения — НЕ рубленые короткие фразы
- Кавычки: "елочки" или "лапки"

### Критические правила стиля

- Пиши от первого лица Алексея
- Stacking: личная история + мысль/модель + образ/метафора — в каждом посте
- Тональность: как письмо умному другу. Искренняя, уместно матерная, умная без академизма
- Финал — вопрос или зеркало, НЕ мораль, НЕ вывод
- Длина: 150-200 слов для Telegram
- НЕ скатывайся в коучинговый шаблон, инфобизнес-тон, пафос или морализаторство
- Конкретика: детали из жизни, цифры, места, ситуации
- Показывай, не поучай. Лучше показать, как сам об это споткнулся

### Анти-паттерны (НИКОГДА не делай)

- Короткие рубленые предложения в стиле "Утро. Кофе. Инсайт."
- Длинное тире (—)
- Жирный/курсив
- Буква ё
- Коучинговые клише ("просто будь собой", "выйди из зоны комфорта")
- Списки в теле поста (списки только если тема требует)
- Пустые обобщения без конкретики

## Шаг 4: Покажи результат

Выведи пост в code block (чтобы сохранить форматирование). Спроси, нужны ли правки.

Если пользователь просит варианты — напиши 2-3 версии с разными хуками.
