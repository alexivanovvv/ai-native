# Meeting Prep

Быстрый анализ контекста клиента перед коуч-сессией. Читает последние транскрипты, about_{Name}.md и файлы папки клиента. Выдаёт один абзац (400–600 символов): что происходило, что открыто, что стоит принести на следующую встречу.

## Usage

```
/meeting-prep Misha
/meeting-prep "Sasha S"
/meeting-prep ~/path/to/client-folder/
```

## Instructions

### Step 1 — Найти материалы клиента

Имя клиента берётся из аргумента. Ищи в этом порядке:

**about_{Name}.md** — личное досье:
```bash
find ~/Library/CloudStorage/Dropbox/_Obsidian/Alex\ Ivanov\ MAIN\ Vault -name "about_*.md" -iname "*{name}*" 2>/dev/null
```

**Папка клиента** в `PROJECTS/01 COACHING CLIENTS/КЛИЕНТЫ/`:
```bash
find "PROJECTS/01 COACHING CLIENTS/КЛИЕНТЫ" -maxdepth 2 -iname "*{name}*" -type d 2>/dev/null
```
Если нашёл — прочитай все `.md` файлы внутри (пропусти файлы >50kb).

**Транскрипты** с этим клиентом в `_TRANSCRIPTS/`:
```bash
find ~/Library/CloudStorage/Dropbox/_Obsidian/Alex\ Ivanov\ MAIN\ Vault/_TRANSCRIPTS -iname "*{name}*" -name "*.md" 2>/dev/null | sort -r | head -3
```
Читай последние 3. Если есть DEBRIEF-файлы (`*DEBRIEF*.md`) — читай их, они компактнее.

### Step 2 — Извлечь главное

Из прочитанного найди:

1. **Последняя тема** — что обсуждалось на последней встрече? Чем закончилось?
2. **Открытые вещи** — что договорились, но не закрыли? Что человек хотел попробовать?
3. **Паттерн** — если виден повторяющийся паттерн в нескольких встречах, назови его одним словом или фразой.
4. **Что стоит принести** — 1–2 темы или вопроса, которые реально стоит затронуть на следующей встрече.

### Step 3 — Написать prep-резюме

Выведи **один абзац, строго 400–600 символов** (считай символы, не слова).

Структура абзаца:
- Предложение 1–2: что было на последней(их) встрече(ах) — конкретно, без воды
- Предложение 3: что осталось открытым или незакрытым
- Предложение 4: если есть паттерн — назови его
- Предложение 5: что стоит принести / спросить на следующей встрече

Тон: рабочий, конкретный, без пересказа. Как короткая записка самому себе перед входом в зум.

После абзаца — одна строка курсивом с источниками: какие файлы прочитал, даты транскриптов.

### Edge cases

- **Клиент не найден:** сообщи какие пути проверял, предложи указать путь вручную.
- **Только 1 транскрипт:** используй его, отметь что это единственная встреча.
- **Нет about_{Name}.md:** работай только с транскриптами, не упоминай отсутствие.
- **Нет транскриптов вообще:** скажи явно, что нет данных, и попроси указать путь.
- **Слишком длинные транскрипты:** читай первые и последние 100 строк + ищи слова "договорились", "следующий шаг", "домашка", "к следующему разу".
