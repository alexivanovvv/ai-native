# Библиотека визуалов

Анимированный геометрический арт для правой половины слайда. Один мотив на слайд, подобранный **по смыслу**. Палитра — **почти-моно: зелёный `#4ade80` (основной) + янтарь `#fbbf24` (акцент, по чуть-чуть)**. Больше цветов не вводить.

## Как устроено

- В `template.html` в `<defs>` лежат **20 готовых мотивов как `<symbol>`** + 5 паттернов (`d_g/d_a` точки, `s_g/s_a` диагональ, `h_g` горизонталь — только зелёный/янтарь).
- Слайд подключает мотив так: `<div class="art"><svg viewBox="0 0 420 560"><use href="#orbital"/></svg></div>`. Класс `mir` → `class="art mir"` даёт зеркальный вариант (больше разнообразия из того же набора).
- Канвас `420×560` (вертикальный — заполняет правую половину). Центр сцены `210,280`.
- Анимация медленная и фоновая: rotate 22–60s, float 5–7s, пульс/ripple 2.4–5s.
- **Зелёный доминирует**, янтарь — 1–2 элемента (ядро, один сектор, галочки). Глубина — через паттерны и opacity, не через новые цвета.

## 20 мотивов и под какой смысл

| `#id` | Мотив | Смысл / когда |
|------|-------|---------------|
| `orbital` | вращающийся веер из секторов | титул, открытие, «вселенная темы» |
| `converge` | два потока-треугольника в центр | двое людей, союз, 1+1=3 |
| `path` | извилистый путь с узлами и бегущей точкой | процесс, маршрут, «как мы идём» |
| `grid` | сетка 3×3 | набор терминов, словарь, таксономия |
| `arc` | две дуги-полукольца + узлы | прогресс «от/к», дуга, мост |
| `diamond` | вращающиеся ромбы | расписание, структура, система |
| `checks` | 2×2 квадрата с галочками | результат, чек-лист, «что унесёте» |
| `sunburst` | лучи-веер из центра | фокус, энергия, главная идея |
| `pulse` | расходящиеся кольца | ритм, частота, связь, коммуникация |
| `network` | узлы + рёбра + бегущая точка | демо, агенты, граф, мультиагентность |
| `concentric` | вложенные вращающиеся квадраты | правила/принципы, слои, фокус внутрь |
| `slabs` | стопка горизонтальных плит | стек, инструменты, сетап, архитектура |
| `shield` | щит-гексагон с замком | приватность, безопасность, данные |
| `funnel` | разбросанные плитки → центр | сбор контекста, агрегация, воронка |
| `stairs` | лестница блоков вверх | шаги, домашка, план действий |
| `spiral` | спираль | рефлексия, итог, «закругляемся», Q&A |
| `rings` | концентрические кольца (крупно) | **разделитель**: обзор блока |
| `interlock` | два сцепленных квадрата | **разделитель**: система / метод |
| `playring` | play-треугольник в кольце | **разделитель**: демо, «смотрим вживую» |
| `arrow` | большая стрелка вверх | **разделитель**: действие, «ваш ход» |

## Правила подбора

- **По смыслу, не по кругу.** Бери мотив из таблицы под тему слайда. Разделители — крупные (`rings/interlock/playring/arrow`).
- **Не повторять подряд.** Соседние слайды — разные мотивы. 20 мотивов + `mir` хватает; одно повторение допустимо, только если далеко разнесено.
- **Новый мотив** добавляй как новый `<symbol>` в `<defs>` (тот же стиль, те же 5 паттернов, 2 цвета) и ссылайся `<use href="#новый">`. Не плоди цвета и не усложняй до «грязи».

## Шаблоны для новых мотивов

Сектор-веер вокруг центра (210,280, r=180), угол 60°:
```svg
<path d="M210 280 L390 280 A180 180 0 0 1 300 436 Z" fill="url(#d_g)" opacity=".85"/>
```
Плавающий прямоугольник с паттерном:
```svg
<rect x="90" y="250" width="240" height="66" rx="8" fill="url(#d_g)" opacity=".7">
  <animateTransform attributeName="transform" type="translate" values="0 0;0 -8;0 0" dur="6s" repeatCount="indefinite"/>
</rect>
```
Расходящееся кольцо (пульс):
```svg
<circle cx="210" cy="280" r="30" fill="none" stroke="#4ade80" stroke-width="3" opacity=".6">
  <animate attributeName="r" values="30;180;30" dur="5s" repeatCount="indefinite"/>
  <animate attributeName="opacity" values=".6;0;.6" dur="5s" repeatCount="indefinite"/>
</circle>
```
